### 1-2. 無人機の操作（MQ-9型「サンドパイパー」）

画面そのものがセンサー映像で、右上の小窓に機体の外観が映ります。

```
機体    W/S 高度   A/D 旋回   Shift/Ctrl 速度   O 自動旋回
カメラ  矢印キー or ドラッグ 首振り   Q/E ズーム   T 追尾   R 赤外線／可視光
攻撃    F 長押し レーザー照射   Space 発射   X 誘導を切る（中止）   M 目標をマーク
```

- ズームして十字に重ねると **識別**（民間か敵かが出る）
- 民間をマーク／民間の近くに着弾させると失敗・減点（交戦規定）
- 撃ったあとでも X で誘導を切れば外せる

### 1-3. F-15 の操縦

```
W/S 機首   A/D 横転   Q/E 方向舵   Shift 出力＋（全開で再燃焼）   Ctrl 出力−   B 減速板
T ロック   1/2/3 兵装（AIM-120 / AIM-9 / 機関砲）   Space 発射   X フレア・チャフ
V 視点（コクピット／外部）   G 脚
```

- HUD：ピッチラダー、方位テープ、速度（kt）・高度（ft）、G、レーダー（±60°/60km）、RWR、兵装、目標枠
- AIM-120 は **撃ったあとも機首を目標に向け続ける**必要あり（外すと誘導が切れる）
- AIM-9 は前方20°・7km 以内、機関砲は見越し点（リード）表示つき
- 失速警報、地面激突、成層圏での失速あり

### 1-4. AeroForge — 機体モデルは Blender の操作手順そのまま

外部モデルを読み込まず、Blender と同じ操作でコードから組み立てています。

| コード | Blender の操作 |
|---|---|
| `loft(sections)` | Add Circle × N → **Bridge Edge Loops** → 端を Grid Fill |
| `plate(outline, th)` | Add Plane → **Extrude Region**（上反角・テーパーつき） |
| `spin(profile)` | 断面を **Spin**（Y軸まわりに回す） |
| `mirror: true` | **Mirror モディファイア** |

収録機体：F-15J / MQ-9型無人機 / Su-27型（敵機）/ C-130型輸送機 / 早期警戒機 /
巡航ミサイル / 対空ミサイル発射機 / 捜索レーダー / 民間バス / 補給車（計10機種）

**同じ設計表から Blender 用 Python を書き出せます。**
ゲーム内：設定 → 機体モデル（Blender）→ Pythonを保存／ストーリー2のハブ → 機体のBlenderスクリプトを保存
リポジトリ：`tools/BLACKSAND-AEROFORGE-v28.34b.py`

Blender 5.x の Scripting → New に貼って Run すると、ゲーム内と同じ形の機体が 10 機種できます。
**格納庫**（ストーリー2のハブ → 格納庫で機体を見る）で、回して三角形数・部品数を確認できます。

### 1-5. 画質が5段階に（ゴミスペ 〜 ウルトラ）

設定 → 画質

| 段階 | 中身 |
|---|---|
| **ゴミスペ** | 影を全部オフ、後処理オフ、霧オフ、粒子・板ポリ（Points / Sprite / Line）オフ、材質を光の計算なしの単色（MeshBasic）に差し替え、解像度 0.62 倍。**ポリゴンの塗りつぶしだけ** |
| 低 / 中 / 高 | これまでどおり |
| **ウルトラ** | 解像度を 1.4 倍に上乗せ（スーパーサンプリング、上限2.6）、影 4096＋やわらかい影、異方性フィルタ最大、影を落とす物を増やす |

- 内部的には既存コードが見る `SAVE.quality`（low/mid/high）は壊さず、
  5段階の選択を `SAVE.qualityMode` に持って対応づけています（ゴミスペ→low、ウルトラ→high）
- ゴミスペから戻すと、預けておいた元の材質に戻ります
- 自前シェーダ（空など）は差し替え対象外（uniforms を触るコードを壊さないため）

## 2. 通常版（別ビルド）への当て方

`patch/v28.34b-modern-air-war.js` は**このゲームの最後のスクリプトの末尾に足すだけ**で動く、
自己完結したパッチです（既存の関数を置き換えず、包んで機能を足す作りにしてあります）。

1. 対象の HTML をテキストエディタで開く
2. 末尾のほうにある起動行

   ```js
   Forge.load().then(()=>ItemModels.load()).then(()=>boot()).catch(err=>{
   ```

   を探す（LITE 以外のビルドでは `boot()` を呼んでいる行）
3. **その行の直前**に `v28.34b-modern-air-war.js` の中身をそのまま貼る
4. `<title>` を `BLACKSAND : AFTERLIGHT — FORGED v28.34β` に変える（任意。JS 側でも上書きします）

前提：three.js r128 相当、`MissionActions` / `PostFX` / `applyQuality` / `wireMenus` / `bindSettings` /
`SAVE` / `writeSave` / `UI` / `toast` / `escapeHTML` が存在すること（v2.1 系はすべて満たします）。
