# CityBuilder Mod

Minecraft Java Edition 用の街づくり MOD。コマンドひとつで日本風の街・高層ビル・鉄道・駅・道路・建物・飛行機を生成できます。

- **対応バージョン**: Minecraft 1.20.1 / Forge 47 以降
- **言語**: 日本語 / English (自動切替)
- **バージョン**: 2.0.0

## 2.0 の新機能

| 機能 | 内容 |
| --- | --- |
| **サーバーが固まらない建設** | 建築はすべてキューに積まれ、1 ティックあたり一定時間 (既定 20 ms) ずつ設置されます。巨大な街でもサーバーが落ちません。進捗はボスバーに表示 |
| **取り消し (Undo)** | `/cb undo` で直前の建築を元の地形ごと復元。チェストの中身も戻ります。1 人あたり 5 件まで (設定可) |
| **中止・状況確認** | `/cb cancel` で建設を中止、`/cb status` で進行状況を表示 |
| **街生成の作り直し** | 道路の種類ごとに正しい幅で区画を割り付け、交差点には横断歩道と信号機。渋谷プリセットの中央交差点は **スクランブル交差点** |
| **走り続ける車と電車** | 外周道路に周回レールを敷き、車が街をぐるぐる走ります。周回鉄道は角がつながり、電車が止まらず一周します |
| **信号機ブロック** (新) | 青→黄→赤が自動で切り替わる横型信号。全信号がゲーム時刻で同期し、縦方向と横方向は逆位相 |
| **エレベーターブロック** (新) | 上に乗ってジャンプで上の階、スニークで下の階へ。高層ビル・ホテル・タワマン・新幹線駅に自動設置 |
| **新しい建物** | `park` (桜の公園と噴水)、`koban` (交番)、`school` (校舎とグラウンド) |
| **駅の作り直し** | 線路の中心線と一致するので `/rail` の上にそのまま駅を置けばつながる。駅名標・改札・ホームドア・駅名指定 |
| **スマホ GUI** | 右クリックでスマホ画面。ミニマップ・時計・天気・ステータス・コンパス (スポーン/死亡地点の方角)・コマンド早見表 |
| **車の見た目** | 車種ごとに色付き車体を載せた専用テクスチャ |
| **地形対応** | 斜面や谷でも建物・道路・線路の下に基礎/築堤を自動で作り、浮かない |

## 導入方法

1. **Minecraft Forge 1.20.1** (47.x) をインストールする
2. Releases (または GitHub Actions の成果物) から `citybuilder-2.0.0.jar` をダウンロード
3. `.minecraft/mods/` フォルダに jar を入れる
4. Forge プロファイルで起動する

> コマンドは **OP 権限 (レベル 2)** が必要です。シングルプレイならワールド作成時に「チートの許可」をオンにしてください。

---

## はじめの一歩

平地で次のコマンドを実行します。

```text
/city downtown ~ ~ ~ 4
```

ボスバーに進捗が表示され、数十秒で高層ビル街が完成します。気に入らなければ:

```text
/cb undo
```

で元の地形に戻ります。

「ちょっと建ててみる」なら:

```text
/base house ~ ~ ~ 12
/skyscraper google ~ ~ ~ 24 24 15 5
```

## コマンド一覧

> すべてのコマンドは **TAB キーで候補補完** できます。

### `/city` — 街全体を生成

```text
/city <preset> <pos> <grid> [seed]
```

| 引数 | 内容 |
| --- | --- |
| `preset` | `downtown` / `shibuya` / `shitamachi` / `residential` / `mixed` |
| `pos` | 起点座標 (北西角)。`~ ~ ~` で現在地 |
| `grid` | 区画数 (2〜8)。区画は 1 辺 24 ブロック、道路幅は種類によって 9〜23 |
| `seed` | (省略可) 乱数シード。同じ値で同じ街を再現。実行時に表示されるシードはクリックでコピー可能 |

| プリセット | 雰囲気 |
| --- | --- |
| `downtown` | 高層ビル中心のオフィス街。ターミナル駅 |
| `shibuya` | 109・百貨店・雑居ビル。中央はスクランブル交差点 |
| `shitamachi` | 下町。商店街アーケード・民家・銭湯・神社・寺 |
| `residential` | 住宅街。一戸建て・タワマン・学校・公園 |
| `mixed` | 全部入り |

### `/skyscraper` — 高層ビル

```text
/skyscraper <type> <pos> <width> <depth> <floors> <floorHeight>
```

| 引数 | 内容 |
| --- | --- |
| `type` | `modern` / `twin` / `pyramid` / `residential` / `hotel` / `google` |
| `width` / `depth` | 5〜64 |
| `floors` | 2〜120 (ワールドの高さ上限を超える場合は自動で調整) |
| `floorHeight` | 3〜10 |

各階の中央にエレベーター、隅に屋上まで続く非常ハシゴがあります。

### `/base` — 建物

```text
/base <type> <pos> <size>
```

`size` は 3〜64。

| 種類 | 内容 |
| --- | --- |
| `house` | 民家 (瓦屋根・畳・囲炉裏) |
| `farm` | 農場 (作物は成長段階がばらばら) |
| `warehouse` | 倉庫 |
| `tower` | 物見やぐら (屋上までハシゴ) |
| `shrine` | 神社 (鳥居・灯籠) |
| `cafe` | カフェ (看板付き) |
| `mansion` | 洋館 (2 階へ上がれる階段) |
| `dojo` | 道場 |
| `konbini` | コンビニ (感圧板で開く自動ドア) |
| `hotspring` | 温泉 |
| `temple` | お寺 (鐘楼) |
| `zakkyo` | 雑居ビル (階ごとにテナントがランダム) |
| `sento` | 銭湯 |
| `shibuya109` | 109 風円柱ビル (屋上まで螺旋階段) |
| `department` | 百貨店 (吹き抜けとエスカレーター) |
| `park` | **新** 公園 (桜・噴水・ベンチ・砂場) |
| `koban` | **新** 交番 |
| `school` | **新** 小学校 (校舎・グラウンド・校門・時計) |

### `/road` — 道路

```text
/road <type> <pos> <length> <axis>
```

`type`: `japanese` / `highway` / `local` / `pedestrian` / `shotengai`、`length`: 5〜2048、`axis`: `x` / `z`。
`pos` は道路の中心線の始点です。

### `/rail` — 鉄道

```text
/rail <type> <pos> <length> <axis>
```

`type`: `standard` (在来線) / `shinkansen` (高架新幹線) / `metro` (地下鉄) / `elevated` (高架)、`length`: 10〜2048。

### `/station` — 駅

```text
/station <type> <pos> <length> <axis> [駅名]
```

| 引数 | 内容 |
| --- | --- |
| `type` | `local` / `terminal` / `shinkansen` |
| `length` | 20〜200 (ホームの長さ) |
| `axis` | `x` / `z` (線路と同じ向き) |
| `駅名` | (省略可) 駅名標に表示する名前。省略すると座標から自動で決まる |

駅の本線は `pos` の中心線上にあるので、`/rail` と同じ座標・向きで置けば線路がつながります。

```text
/rail standard ~ ~ ~ 300 x
/station local ~100 ~ ~ 40 x 桜ヶ丘
```

### `/plane` — 飛行機

```text
/plane <type> <pos> <facing>
```

`type`: `cessna` / `jet` / `biplane`、`facing`: `east` / `west` / `north` / `south`。

### `/cb` (`/citybuilder`) — 管理

| コマンド | 内容 |
| --- | --- |
| `/cb undo` | 自分の直前の建築を取り消す (何回でも、履歴の数まで) |
| `/cb cancel` | 自分の建設を中止 (設置済み部分は `/cb undo` で戻せる) |
| `/cb cancel all` | 全員の建設を中止 |
| `/cb status` | 実行中・待機中の建設と取り消し可能な履歴数 |
| `/cb help` | コマンド一覧 |

## ブロックとアイテム

クリエイティブインベントリの「**シティビルダー**」タブに収録されています。

| 名前 | 説明 |
| --- | --- |
| **セダン / タクシー / トラック / 路線バス / スポーツカー** | 線路の上で右クリックすると、向いている方向に走り出す。車種ごとに色の違う車体が乗る。乗車も可能 |
| **スマートフォン** | 右クリックでスマホ画面を開く。ミニマップ (北が上・高低で陰影)、時計 (月齢)、天気 (気温)、ステータス、コンパス (スポーン地点・死亡地点の方角と距離)、コマンド早見表。Shift+右クリックで現在地をチャットに共有 |
| **テレポーターレーザー** | 右クリックで視線方向にレーザー発射 (既定 128 ブロック)。壁・天井・液体の中に埋まらない安全な位置を探して着地 |
| **エレベーター** | 同じ縦の列に複数置き、上に乗ってジャンプで上へ、スニークで下へ移動 (最大 96 ブロック) |
| **信号機** | 置くだけで青→黄→赤を繰り返す。南北向きと東西向きは逆位相 |

## 設定

ワールドの `serverconfig/citybuilder-server.toml` で変更できます。

| 項目 | 既定値 | 内容 |
| --- | --- | --- |
| `msPerTick` | 20 | 1 ティックあたり建設に使う時間 (ms)。大きいほど速いが重くなる |
| `maxBlocksPerJob` | 30000000 | 1 回のコマンドで計画できる最大ブロック数 |
| `maxUndo` | 5 | 取り消し履歴の件数 (プレイヤーごと) |
| `foundationDepth` | 24 | 斜面で基礎を下に延ばす最大の深さ (0 で無効) |
| `showProgressBar` | true | 進捗ボスバーの表示 |
| `laserRange` | 128 | テレポーターレーザーの射程 |

## 修正した不具合 (1.0.0 → 2.0.0)

- 周回鉄道の 4 つの角で、片側の線路がフェンスと空気で上書きされて途切れ、トロッコが止まっていた
- 駅の線路が中心から ±4 ずれていて、`/rail` の線路にも街の周回鉄道にもつながらなかった
- 街中心部で縦横の車用レールが交差し、交点で片方の線路が直角に置き換わっていた。また行き止まりの直線だったため車がすぐ止まっていた
- 幹線道路 (幅 23) や日本風道路 (幅 15) を 9 ブロックの道路枠に置いていたため、隣の区画に食い込みビルと重なっていた
- 交差点を中央分離帯・植え込み・木が塞いでいた
- 木や生け垣の葉が `persistent=false` で設置され、しばらくすると自然に消えていた
- ドア・ベッドが片側だけ設置され、壊れた状態になっていた
- 高層ビル・雑居ビル・物見やぐらのハシゴが天井で塞がれて上の階に行けず、支えの無いハシゴは消えていた
- 高層ビルの「エレベーター」は鉄ブロックで塞がった縦穴で使えなかった。ピラミッド型ビルはコア位置の計算ミスで縦動線が無かった
- ホテルの客室壁が廊下を塞ぎ、タワマンの住戸は扉の無い密閉空間だった
- 109 の螺旋階段が斜めに並んで登れず、百貨店のエスカレーターは向きが逆で頭上が塞がっていた
- 洋館の階段が 2 階の床で塞がっていた
- 民家の囲炉裏が X 座標を Z に使っていたため、家の外の無関係な場所に焚き火が出現していた
- セスナのエンジンが金床で、空中に置くと落下していた
- 宙に浮いた看板・ランタン・鐘・魂の炎が、周囲の更新で外れてアイテム化していた
- 窓ガラス・鉄格子・フェンスがつながらず細い棒になっていた (設置後に形状を再計算するように)
- 建物の外周の地面や道路にハーフブロックの縁取りが付いていた
- 巨大なサイズを指定するとメインスレッドで一度に設置してサーバーが固まっていた
- テレポーターレーザーで壁際や天井に撃つと、ブロックに埋まって窒息することがあった
- 商店街の看板や吊り提灯が浮いていた / ローカル道路に宙に浮いた鉄ブロックがあった

## トラブルシューティング

| 症状 | 対処 |
| --- | --- |
| `Unknown or incomplete command` | OP 権限があるか確認 (`/op <player>`) |
| 「不明な種類: XXX」 | 種類のスペル違い。TAB キーで候補が出ます |
| 建設が遅い | `msPerTick` を上げる (最大 45)。サーバーが重いなら下げる |
| 「大きすぎます」と出る | サイズを小さくするか `maxBlocksPerJob` を上げる |
| 建てた物を消したい | `/cb undo` |
| アイテムのテクスチャが紫黒 | jar を入れ直してリソースの再読込 (F3+T) |

## ソースからビルド

JDK 17 が必要です。

```bash
git clone https://github.com/haruMCM-alt/City-Builder-MOD-for-Minecraft-1.20.1.git
cd City-Builder-MOD-for-Minecraft-1.20.1
./gradlew build
```

成果物は `build/libs/citybuilder-2.0.0.jar` に出力されます。push と PR ごとに GitHub Actions でもビルドされます。

```bash
./gradlew runClient   # クライアント起動
./gradlew runServer   # 専用サーバー起動 (run/ に生成)
```

### ソースの構成

| パッケージ | 内容 |
| --- | --- |
| `engine` | `BlockCanvas` (設置前のバッファ)、`BuildJob` / `BuildManager` (ティック分割設置・形状再計算・取り消し) |
| `builders` | 街・ビル・建物・道路・鉄道・駅・飛行機の設計 |
| `blocks` | エレベーター・信号機 |
| `items` | 車・スマホ・レーザー |
| `client` | スマホ画面 |
| `commands` | 全コマンド |

### テクスチャを再生成

車・エレベーター・信号機のテクスチャは標準ライブラリだけで動くスクリプトで生成しています:

```bash
python3 tools/build_textures.py
```
