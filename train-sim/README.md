# 宇都宮線 運転シミュレーター

電車でGO! 風の 3D 電車運転シミュレーターです。ブラウザ（Three.js）で動きます。

- **路線**: 宇都宮線 上野 → 宇都宮（約 109 km・23 駅）。区間は自由に選べます
- **車両**: E231系1000番台（デフォルト・グリーン車付き 15 両）／E233系3000番台／211系3000番台／115系 湘南色
- **3D モデル**: 実車の写真を参考に Blender で作成（`blender/build_models.py` で再生成。参考資料は `blender/REFERENCES.md`）
  - 車体は厚みのある中空シェルで、側窓から客室が見えます。客室は 1 人ずつ区切ったバケットシート（モケット地）・大型袖仕切り・三角つり革（優先席は黄色）・パイプ荷棚・天井の空調吹出口と照明カバー・中吊り広告・窓上広告・戸袋・ドア上の案内表示器（E231 は LED、E233 は LCD）・半分下ろしたカーテン・床の黄色い注意表示まで作り込み。グリーン車は 2 階建ての両デッキにリクライニングシート
  - **車輪が走行距離に合わせて回転**し、**ドアが開閉**します（駅ではホーム側だけが開き、開くとき約 1.9 秒・閉まるとき約 1.2 秒で戸袋に収まる）
  - 視点「車内」で、モーター車の客室に立った乗客の目線（ドア上の案内表示「次は〜」・駅名・号車・時刻が実際に切り替わります）
  - ボルスタレス台車（空気ばね・軸箱・ディスクブレーキ・主電動機）、車側灯、車番表記、ステンレスのヘアライン仕上げと床下まわりの汚れ（シェーダー）
  - 運転台は E231/E233 の高運転台の寸法（運転士の目の高さ 2.97 m）で、黒いフード・3 画面の LCD（速度計・BC/MR 圧力計、TIMS の次駅・時刻、ノッチ・ATS 表示が走行に合わせて動く）、ワンハンドルマスコン（奥へ押すとブレーキ）、時刻表差し・運転席・仕切り
  - 運転台は天井の有孔パネル・壁の化粧板・ゴム床・シボ加工のフードなどの質感、BC/MR の圧力計・ボタン類・表示灯・スイッチ・消火器などを追加し、Cycles で焼いたアンビエントオクルージョン（陰影）を貼っています
  - 客室には座っている乗客・ドア付近に立つ乗客（外から窓越しにも見えます）
  - 画面の文字は BIZ UDPゴシック、LED 表示器はドット文字（DotGothic16）を 1 ドットずつ発光させて描画（Google Fonts）
- **景色**: 大気散乱の空と太陽、雲、遠景の山並み（日光連山・筑波山）、地平線の街並みと鉄塔、季節感のある田園（実った稲・刈り取り後の田）
  - 赤羽付近・浦和付近の高架橋、荒川・利根川・渡良瀬川のトラス橋（河川敷の野球場・堤防つき）、勾配のある築堤
  - 都心はマンション・オフィス・商店、郊外は戸建て住宅、田園部は屋敷林のある集落・ビニールハウス・竹林
  - 建物は瓦屋根・雨どい・ベランダと洗濯物・エアコン室外機・太陽光パネル・ブロック塀や生け垣、マンションのバルコニー、ビルの屋上設備・看板（架空の店名）、商店の日よけ・突き出し看板・自販機など。線路から遠い建物ほど簡略化して軽量化
  - 踏切（遮断機・警報灯・警報音）と道路を走る車、並行道路の電柱と電線、駅（橋上駅舎・高架下駅舎・ホーム屋根・駅名標）
  - ホームには乗車位置に 2 列で並ぶ人・歩く人・ベンチに座る人（服装 8 種類）、吊り下げ式の発車標（LED）と時計、分別ゴミ箱
  - 遠景の山並みは尾根のある稜線（日光連山・筑波山の双耳峰・秩父）を 2 層に重ね、空気遠近で霞ませています
  - 仕上げのカラーグレーディング（コントラスト・彩度・影は寒色/中間は暖色・周辺減光・粒状感）
  - 描画品質はメニューで選択（最高：影・アンビエントオクルージョン・ブルーム／高／軽量）
- **走行音**: Web Audio API で合成（ドアチャイムと戸閉音のみ録音素材）。詳しくは下の「音響システム」
  - VVVF インバータ音は、インバータ → モーター電流 → 電磁力 → 車体の共振という物理モデルで計算（E231・E233 は実車の変調パターン）
  - 音源はすべて立体配置。カメラ（聞き手）との距離から音の到達遅れを計算するので、**ドップラー効果**（すれ違い・通過・踏切）が自然に生じます
  - 直流モーター車（211系・115系）は電機子の唸り・整流子音・ギア・冷却ファン、カム軸の進段音つき
  - レールのジョイント音（全車軸・25 m ごと・分岐器）、転動音、鉄橋の響き、風切り音、ブレーキの空気音・停止前のきしみ、曲線のきしみ、警笛、ATS ベル、踏切の警報音
  - 駅のホームのざわめき、郊外・田園の鳥の声（立体配置）
  - E231系・E233系のドアチャイム＋戸閉（リニアモーター式）は録音（`assets/sounds/door_close_e231.mp3`）。他形式は合成チャイム
- **車内放送**: 実際の車内放送の録音を、駅ごとの「次は〜」「まもなく〜」に合わせて再生
- **発車メロディ**: 発車メロディ集の録音から、各駅の発車前にメロディを再生（駅ごとに割り当てを変更可）
- **メニュー**: 選んだ車両を 3D でぐるりと眺めるプレビュー
- **時刻表**: 録音中の車掌放送に出てくる実際の時刻（上野 8:51 発 → 宇都宮 10:34 着）に合わせています

## 音響システム

`src/audio/sound.js`（エンジン）・`spatial.js`（立体音響）・`traction-worklet.js`（モーター音の合成）

- **立体音響とドップラー効果**: 動く音源はすべて「伝搬遅延（距離 ÷ 343 m/s）→ 空気吸収のローパス → 距離減衰 → 左右定位」を通ります。遅延時間が距離に合わせて連続的に変わるため、近づく音は高く、遠ざかる音は低く聞こえ、音が届くまでの時間差も再現されます（式で音程を変えるのではなく、物理的に生じるドップラー効果）。聞き手はカメラの位置と向きに追従します
- **自列車**: 各車両に転動音（車輪・レールの粗さ、速度で中心周波数が上がる）、各モーター車にモーター音（電動車ごとに別ユニット：車輪径の差・キャリア位相が違うので、編成全体で自然に広がります）、全車軸のジョイント音、先頭の警笛。トラス橋・高架では鉄橋・高架の響きが加わります
- **他の列車・踏切**: すれ違う列車は自前のモーター音・転動音・ジョイント音を持ち、通過時にドップラー効果で音程が下がります。踏切の警報音も踏切の位置から鳴るので、通過すると音程が変わります
- **聞く場所**: 運転台・客室では車体の遮音（ローパス）を通り、ドアが開くと外の音が入ります。外の視点では周囲の反響（コンボリューション・リバーブ）が加わります
- **VVVF の物理モデル**（AudioWorklet、4 倍オーバーサンプリング）
  1. 2 レベル 3 相インバータ：正弦波と三角波キャリアの比較（非同期・同期 N パルス・広域 3 パルス・1 パルス、ランダム変調）
  2. モーター相電圧から基本波を除いた分を漏れインダクタンスで積分 → PWM のリプル電流
  3. 磁束 × リプル電流（空間ベクトルの内積・4 極モード・トルクリプル）＋リプル電流の 2 乗 → 固定子に働く電磁力
  4. 電磁力がモーター枠・台車の共振（バンドパス群）を励振
  5. 機械音：歯車のかみ合い（ピニオン歯数 × モーター回転数、高調波と車輪 1 回転ごとの側帯波）、冷却ファン、回転子スロット高調波
- **実車データ**（調査結果。出典は下記）
  - E231系1000番台：歯車比 14:99（7.07）、MT73、日立 2 レベル IGBT。標準は機器更新車の音（非同期 525 Hz → 約 900 Hz → 9 パルス → 広域 3 パルス → 1 パルス、回生では非同期のキャリアが約 200 Hz まで下がる）。メニューで未更新車（SC59A/SC77：1045 Hz 一定 → 710 Hz へ下降 → 1750 Hz へ急上昇 → 広域 3 パルス → 1 パルス、いわゆる「墜落」）に切り替え可能
  - E233系3000番台：歯車比 1:6.06、MT75、日立 SC98（525 Hz → 約 905 Hz → 9 パルス 約 33 km/h → 広域 3 パルス → 1 パルス 約 43 km/h）
  - 211系3000番台：歯車比 16:83、MT61（外扇形）、CS57A カム軸／115系：歯車比 17:82、MT54、CS15 カム軸
  - 出典：VVVF-Simulator のパターン YAML（https://github.com/VvvfGeeks/YAML-Files ・ `JRE_E231_HITACHI.yaml` など）、VVVF名鑑（https://vvvfdb.stars.ne.jp/ ・ H2I-2 / H2I-3 の分類とスペクトログラム）、日立評論 2000 年 4 月号、Wikipedia 日本語版の各形式の記事。切替速度の一部（E231 更新車）は公開データがなく、E233系3000番台の比率からの推定です

## 遊び方

ES モジュールと glTF を読み込むため、ローカルサーバー経由で開いてください。

```bash
cd train-sim
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### 操作

| キー | 操作 |
|---|---|
| ↑ / W / Z / ホイール上 | 力行側へ（ノッチを進める・ブレーキを緩める） |
| ↓ / S / A / ホイール下 | ブレーキ側へ |
| Space / N | ニュートラル |
| Q | 常用最大ブレーキ |
| E / Backspace | 非常ブレーキ |
| H（長押し） | 警笛 |
| C / V | 視点切替（運転台・車内・正面・側面・後方上空・沿線） |
| Enter / F | 停車中、発車時刻まで早送り |
| T | 時刻表 |
| M / Esc | 消音 / 一時停止 |
| ドラッグ | 運転台・車内で見回す（ダブルクリックで正面） |

ゲームパッド（十字キー上下でノッチ、A=N、B=EB、Y=視点、X=早送り）と、画面のタッチボタンにも対応しています。

### 採点

- 停止位置目標「15」との誤差：±5 cm 以内で「ぴったり停止！」(+30)、±50 cm で GREAT(+20)、±1 m で GOOD(+10)。行き過ぎ 3 m 超はオーバーラン(-20)
- 到着時刻：±1 秒で「定着」(+20)。遅れ・早着は減点
- 高いブレーキ段のまま停止すると「停止衝動」(-5)、早発(-5)、通過(-50)、ATS-P 作動(-10)
- 制限速度 +5 km/h を超えるパターンに当たると ATS-P が常用最大ブレーキをかけます

## 車内放送の音声について

車内放送は、ひごくま / Higokuma 氏の「宇都宮線 普通宇都宮行き 車内放送（上野→宇都宮）」(https://www.youtube.com/watch?v=RN1OnfJnqWg) の音声を
`assets/sounds/utsunomiya_announce.mp3` として同梱し、起動時に自動で読み込みます（mp3 / モノラル 56 kbps に変換）。
作者は二次利用の際に一声かけてほしいとしています（連絡フォーム: https://forms.gle/1LmTKectETrFEooN9 ）。

駅ごとの区切り位置（`src/audio/announce-cues.js`）は、音声認識（Whisper）で「次は〜」「まもなく〜」の位置を求め、
発話の切れ目に合わせて決めています。メニューで「音声合成」を選ぶとブラウザの音声合成で放送します。

## ドア閉の音について

`assets/sounds/door_close_e231.mp3` は、チャンネルゆうぴー氏の E231系・E233系（リニアモーター式ドア）のドア閉の動画の音声から、
ドアチャイムと戸閉の 1 回分（約 3.9 秒）を切り出したものです。

## 発車メロディの音声ファイルについて

発車メロディには、武蔵野快速氏の「JR宇都宮線 発車メロディ集」(https://www.youtube.com/watch?v=2vYpq3ri4tY) の音声を使います。
こちらも**音声ファイルはリポジトリに含めていません**（メロディの著作権表記：株式会社スイッチ）。
メニューの「発車メロディ」でファイルを選ぶか、`train-sim/assets/audio/utsunomiya_melody.m4a` に置いてください。

- 録音は「東京→宇都宮の駅順に、上り→下り、各曲 2 回」「最後に使用終了の 4 曲」という構成です。無音区間で 38 曲に切り分け、重複を除いています（`src/audio/melody-cues.js`）
- 録音には駅名の音声が入っておらず（動画の画面表示のみ）、どの曲がどの駅かは音だけでは確定できません。初期の割り当ては収録順からの推定です
- メニューの「駅ごとの割り当て」で各駅の曲を ▶ で試聴しながら選び直せます（ブラウザに保存）
- 発車時刻の前にメロディ → ドアチャイム → 戸閉 の順で進みます。停車時間が短い駅では車掌がボタンを離したように途中で止まります
- ファイルが無い場合は、仮の合成メロディ（オリジナル）を鳴らします

## 3D モデルの再生成（Blender）

```bash
blender -b -P train-sim/blender/build_models.py
```

`assets/models/*.glb`（車両 4 形式・運転台・沿線設備）と、編集用の `blender/train_models.blend` が出力されます。
車両は `blender/cars.py`（断面・ドア配置・帯の高さ・前面レイアウトを形式ごとに定義）、共通処理は `blender/lib.py` です。
