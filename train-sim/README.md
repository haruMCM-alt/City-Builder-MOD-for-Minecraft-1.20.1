# 宇都宮線 運転シミュレーター

電車でGO! 風の 3D 電車運転シミュレーターです。ブラウザ（Three.js）で動きます。

- **路線**: 宇都宮線 上野 → 宇都宮（約 109 km・23 駅）。区間は自由に選べます
- **車両**: E231系1000番台（デフォルト・グリーン車付き 15 両）／E233系3000番台／211系3000番台／115系 湘南色
- **3D モデル**: すべて Blender で作成（`blender/build_models.py` で再生成できます）
- **走行音**: すべて Web Audio API で合成（録音素材なし）
  - VVVF インバータ音：3 相 PWM 波形（非同期・同期 N パルス・1 パルス）を実際に計算して発音
  - 直流モーター車（211系・115系）はギア・モーターの唸り、115系は抵抗制御のカム音つき
  - レールのジョイント音（25 m ごと・分岐器）、転動音、風切り音、ブレーキの空気音・停止前のきしみ、ドアチャイム、警笛、ATS ベル、すれ違い
- **車内放送**: 実際の車内放送の録音を、駅ごとの「次は〜」「まもなく〜」に合わせて再生
- **時刻表**: 録音中の車掌放送に出てくる実際の時刻（上野 8:51 発 → 宇都宮 10:34 着）に合わせています

## 遊び方

ES モジュールと glTF を読み込むため、ローカルサーバー経由で開いてください。

```bash
cd train-sim
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
```

### 操作

| キー | 操作 |
|---|---|
| ↑ / W / Z / ホイール上 | 力行側へ（ノッチを進める・ブレーキを緩める） |
| ↓ / S / A / ホイール下 | ブレーキ側へ |
| Space / N | ニュートラル |
| Q | 常用最大ブレーキ |
| E / Backspace | 非常ブレーキ |
| H（長押し） | 警笛 |
| C / V | 視点切替（運転台・側面・後方上空・沿線） |
| Enter / F | 停車中、発車時刻まで早送り |
| T | 時刻表 |
| M / Esc | 消音 / 一時停止 |
| ドラッグ | 運転台で見回す（ダブルクリックで正面） |

ゲームパッド（十字キー上下でノッチ、A=N、B=EB、Y=視点、X=早送り）と、画面のタッチボタンにも対応しています。

### 採点

- 停止位置目標「15」との誤差：±5 cm 以内で「ぴったり停止！」(+30)、±50 cm で GREAT(+20)、±1 m で GOOD(+10)。行き過ぎ 3 m 超はオーバーラン(-20)
- 到着時刻：±1 秒で「定着」(+20)。遅れ・早着は減点
- 高いブレーキ段のまま停止すると「停止衝動」(-5)、早発(-5)、通過(-50)、ATS-P 作動(-10)
- 制限速度 +5 km/h を超えるパターンに当たると ATS-P が常用最大ブレーキをかけます

## 車内放送の音声ファイルについて

車内放送には、ひごくま / Higokuma 氏の「宇都宮線 普通宇都宮行き 車内放送（上野→宇都宮）」(https://www.youtube.com/watch?v=RN1OnfJnqWg) の音声を使います。
作者が「二次利用の際は一声かけてほしい」としているため、**音声ファイル自体はこのリポジトリに含めていません**。

使い方は 2 通りあります：

1. メニューの「ファイルを選択（.m4a）」で手元の音声ファイルを選ぶ（ブラウザ内でだけ使われます）
2. `train-sim/assets/audio/utsunomiya_announce.m4a` に置く（`.gitignore` 済み。起動時に自動で読み込みます）

駅ごとの区切り位置（`src/audio/announce-cues.js`）は、音声認識（Whisper）で「次は〜」「まもなく〜」の位置を求め、
発話の切れ目に合わせて決めています。ファイルが無い場合はブラウザの音声合成で代わりに放送します。

## 3D モデルの再生成（Blender）

```bash
blender -b -P train-sim/blender/build_models.py
```

`assets/models/*.glb`（車両 4 形式・運転台・沿線設備）と、編集用の `blender/train_models.blend` が出力されます。
すべてスクリプトで組み立てているため、寸法や塗装はスクリプトの `SERIES` を書き換えて調整できます。

## ファイル構成

```
train-sim/
├── index.html            メニュー・HUD
├── css/style.css
├── src/
│   ├── main.js           起動・入力・カメラ・対向列車・メインループ
│   ├── route.js          駅・線形（曲線）・制限速度
│   ├── world.js          線路・架線・駅・街並みの生成（200 m ごとに逐次生成）
│   ├── trainmodel.js     編成の組み立てと線路への配置
│   ├── physics.js        運動方程式・ワンハンドルマスコン・ATS-P
│   ├── vehicles.js       車両性能・編成・音の設定
│   ├── timetable.js      時刻表の生成
│   ├── game.js           ドア・発車・停車判定・採点・放送のきっかけ
│   ├── hud.js            速度計・ノッチ表示・停止位置ゲージ
│   └── audio/
│       ├── sound.js            走行音エンジン
│       ├── traction-worklet.js VVVF / モーター音の合成（AudioWorklet）
│       ├── announce.js         車内放送の再生
│       └── announce-cues.js    録音内の駅ごとの区切り位置
├── assets/models/        Blender から書き出した glTF
└── blender/              モデル生成スクリプトと .blend
```

駅間距離や曲線は実際の路線を参考にしたゲーム用の再現で、実際の線形・信号・制限速度とは異なります。
