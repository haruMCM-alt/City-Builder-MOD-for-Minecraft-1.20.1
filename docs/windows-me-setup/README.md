# Windows Me セットアップ（再現）

Windows Millennium Edition のセットアップとデスクトップを、**実機の画面を実測して**再現した、
実際に操作できる非公式のファンメイド作品です。HTML / CSS / JavaScript だけで動きます。

## 開き方

`index.html` をブラウザで開くだけで動きます（ビルド不要、外部への通信なし）。

単一の HTML ファイルに書き出す場合:

```sh
python3 docs/windows-me-setup/build.py > windows-me-setup.html
```

## 起動の流れ

| 状態 | 起動したときの動き |
| --- | --- |
| はじめて開いたとき | MS-DOS のセットアップ画面から始まり、セットアップ → ログオン → デスクトップ |
| 1 度セットアップを終えたあと | Windows Me のパッケージが表示され、クリックするとフェードして起動ロゴ → そのままデスクトップ |

- 表示は**全画面が既定**です。ブラウザの仕様上、本当の全画面にはクリックかキー入力が必要なため、
  開いた直後はページいっぱいに表示し、最初の操作でブラウザの全画面に切り替えます。
- 画面の上端にマウスを移動すると、全画面の切り替え・枠付き表示・音・再生速度・**セーブを消去** のメニューが出ます。

## セーブ

セットアップを終えると、次の内容がこのブラウザ (localStorage) に自動的に保存されます。

- インストール済みの状態と、セットアップで入力した内容（名前・プロダクト キー・コンピュータ名など）
- C ドライブのファイルとフォルダ（メモ帳・ペイントで保存したもの、デスクトップに作ったもの）
- ごみ箱、最近使ったファイル、壁紙・音量・時計などの設定、マインスイーパの最高記録
- システムの復元の復元ポイント

保存先は閲覧しているブラウザだけです。プライベート ウィンドウなど保存が許可されない環境では、その回限りになります。

## デスクトップで動くもの

| 分類 | 内容 |
| --- | --- |
| エクスプローラ | マイ コンピュータ、マイ ドキュメント、各フォルダ。新規作成・名前の変更・削除・切り取り/コピー/貼り付け・プロパティ。左側に Me 風のフォルダ説明 |
| ごみ箱 | 削除したものが入り、元に戻す・完全に削除・ごみ箱を空にする（RECYCLE.WAV） |
| メモ帳 | 開く・上書き保存・名前を付けて保存、検索、日付と時刻、右端で折り返す、変更の保存確認 |
| ペイント | 鉛筆・ブラシ・消しゴム・塗りつぶし・スポイト・直線・四角形・楕円、28 色パレット、元に戻す、反転、保存、**壁紙に設定** |
| 電卓 | 四則演算・メモリ・√・%・1/x、キーボード入力 |
| マインスイーパ | 初級・中級・上級、旗と ?、最高記録の保存 |
| Internet Explorer | 2000 年ごろの Google トップ ページを再現し、**Google 検索・Google マップ・Wikipedia** を埋め込み表示。戻る/進む、お気に入り、ホーム ページの設定 |
| Windows Media Player | Windows Me のシステム サウンドを再生、ビジュアライゼーション |
| Outlook Express | 受信トレイとようこそメール（送受信はしません） |
| システムの復元 | 復元ポイントの作成と復元。復元しても マイ ドキュメント は変更されません |
| その他 | 検索、ヘルプとサポート、MS-DOS プロンプト（DIR, CD, TYPE, MD, RD, DEL, REN, COPY など）、ファイル名を指定して実行、コントロール パネル（画面・日付と時刻・システム・サウンド・アプリケーションの追加と削除・インターネット オプション・タスク バー）、右クリック メニュー、音量、ログオフ、終了（電源オフ / 再起動 / MS-DOS モード / スタンバイ） |

Google 検索などのページは iframe で埋め込んでいます。サイトの設定や閲覧環境によって
表示できない場合は、IE の [ファイル] → [お使いのブラウザで開く] で開けます。
Windows Me の全機能を備えているわけではなく、含まれていないプログラムを開くとその旨を表示します。

## 操作

- マウス: クリック / ダブルクリック / 右クリック / タイトル バーのドラッグ / 右下の角でサイズ変更 / タイトル バーのダブルクリックで最大化
- `Enter` 既定のボタン、`Esc` キャンセル、`Tab` フォーカス移動、`Alt` + 下線付きの文字（メニュー バーも開けます）
- `Alt+Enter` 全画面の切り替え
- アプリごとのショートカット（`Ctrl+S` 保存、`Ctrl+Z` 元に戻す、`F2` 名前の変更、`Delete` 削除 など）

## 再現の方法

- **レイアウト**: 640×480 の実機スクリーンショットをピクセル単位で実測して配置しています。
- **色**: セットアップ中は VGA 16 色、デスクトップは `#3a6ea5` と `#d4d0c8`、タイトル バーは `#0a246a → #a6caf0`。
- **画像**: ロゴ・アイコン・背景は `assets/` の画像で、ドット絵のまま拡大表示します（0.25 刻み）。
- **音**: Windows Me に収録されている WAV をそのまま鳴らします。セットアップ中のエラー音だけは PC スピーカー相当の合成音です。
- **フォント**: 字形がドットでできた PixelMplus12（12px）と DotGothic16（16px）を同梱し、全画面でもドット調が崩れないようにしています。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` | ラッパとスタイル |
| `js/core.js` | DOM ヘルパ、サウンド、素材参照、コントロール、ダイアログ |
| `js/save.js` | セーブ（localStorage）と仮想ファイル システム |
| `js/setup.js` | MS-DOS 画面からログオンまでのセットアップ本編 |
| `js/desktop.js` | ウィンドウ管理、メニュー、ファイル ダイアログ、デスクトップ、スタート メニュー、終了処理 |
| `js/apps.js` | エクスプローラ、メモ帳、ペイント、電卓、マインスイーパ、IE、Media Player など |
| `js/main.js` | 画面の組み立て、全画面、パッケージ画面、キーボード操作 |
| `assets/` | 画像、音（`sounds/`）、フォント（`fonts/`） |
| `build.py` | すべてを 1 つの HTML にまとめるスクリプト |
