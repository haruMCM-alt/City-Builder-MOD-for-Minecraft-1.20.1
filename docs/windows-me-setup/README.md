# Windows Me セットアップ（再現）

Windows Millennium Edition のセットアップ画面を、HTML / CSS / JavaScript だけで再現した
**非公式のファンメイド作品**です。外部の画像素材は一切使っておらず、ロゴ・アイコン・
イラストはすべてこのリポジトリ内の SVG と CSS で描き起こしています。

## 開き方

`index.html` をブラウザで開くだけで動きます（ビルド不要、外部依存はフォントのみ）。

```
docs/windows-me-setup/index.html
```

単一 HTML ファイルとして書き出したい場合:

```sh
sh docs/windows-me-setup/build.sh > windows-me-setup.html
```

## 収録している流れ

| 段階 | 内容 |
| --- | --- |
| 実モード | MS-DOS 風の青い起動画面（Enter=続行 / F3=終了）、ScanDisk |
| 情報の収集 | ようこそ → 使用許諾契約書 → プロダクト キー → ディレクトリ → 準備 → セットアップ オプション → ユーザー情報 →（カスタム時）コンポーネント選択 → コンピュータ情報 → 国/地域 → 起動ディスク → 確認 |
| コピー | ブロック式プログレス バー、CAB/ファイル名の表示、Me の機能を紹介するスライドショー 6 枚 |
| 再起動 | 15 秒カウントダウン → 起動ロゴ（下部を流れるグラデーション バー） |
| 設定の完了 | ハードウェア検出、新しいハードウェアの検出ダイアログ、設定の更新、タイム ゾーン |
| ログオン | Windows へのログオン、パスワードの確認入力 |
| デスクトップ | スタート メニュー、タスク バーと時計、マイ コンピュータ、コントロール パネル、メモ帳、ペイント、MS-DOS プロンプト、Windows の終了 |

## 操作

- マウス: クリック / デスクトップ アイコンはダブルクリック / ウィンドウはタイトル バーでドラッグ
- `Enter` 既定のボタン、`Esc` キャンセル、`Tab` フォーカス移動
- `Alt` + 下線付きの文字 でショートカット（例: `Alt+N` = 次へ）
- 画面の下のバー: 効果音、走査線、再生速度（×1 / ×2 / ×4）、表示倍率、最初からやり直す

入力内容（名前・プロダクト キー・コンピュータ名など）は最後のデスクトップまで引き継がれ、
[コントロール パネル] → [システム] で確認できます。

## 作りかた・寄せかた

- **フォント**: `MS UI Gothic` / `MS Gothic` を最優先で参照し、無い環境では Google Fonts の
  `DotGothic16`（ビットマップ調）にフォールバックします。ロゴの欧文は
  `Franklin Gothic Medium` 系を指定。
- **色**: 3D オブジェクトは Windows Me 既定の `#d4d0c8`、選択色は `#000080`、
  タイトル バーは `#0a246a → #a6caf0` のグラデーション。セットアップ左ペインは
  紺 → ティールのグラデーションで Me のブランド カラーに寄せています。
- **コントロール**: ボタン・チェック ボックス・ラジオ・リスト ボックス・スクロール バーまで、
  9x の 1px 立体枠（ハイライト / シャドウ / 内側の淡色）を CSS で再現。
- **プログレス バー**: 9x 特有のブロック分割を `repeating` グラデーションで表現。
