# Windows Me セットアップ（再現）

Windows Millennium Edition のセットアップを、**実機の画面を実測して**再現した、
実際に操作できる非公式のファンメイド作品です。HTML / CSS / JavaScript だけで動きます。

## 開き方

`index.html` をブラウザで開くだけで動きます（ビルド不要、外部依存はフォントのみ）。

単一の HTML ファイルに書き出す場合:

```sh
python3 docs/windows-me-setup/build.py > windows-me-setup.html
```

## 収録している流れ

| 段階 | 内容 |
| --- | --- |
| 実モード | MS-DOS の青いテキスト画面（Enter=続行 / F3=終了）、ScanDisk |
| 第1フェーズ（16 色・青地） | ウィザードの準備 → ようこそ → 使用許諾契約書 → プロダクト キー → ディレクトリの選択 → セットアップ オプション → ユーザー情報 → Windows コンポーネント（一覧から選択も可）→ ネットワーク ID → 国/地域 → タイム ゾーン → 起動ディスク → コピー開始の確認 |
| ファイルのコピー | 青地のビルボード 5 枚、左パネルの「ファイルのコピー状況」バー、残り時間 |
| 再起動 | 15 秒カウントダウンの再起動ダイアログ → 起動ロゴ |
| 第2フェーズ（白地にロゴ） | ハードウェアのセットアップ → ハードウェアの検出 → 再起動 → 項目のセットアップ（コントロール パネル ほか） |
| ログオン | Windows パスワードの入力、パスワードの確認入力 |
| デスクトップ | スタート メニュー（3 階層のカスケード）、クイック起動、タスク バーと時計、マイ コンピュータ、コントロール パネル（画面・日付と時刻・システム）、メモ帳、ペイント、MS-DOS プロンプト、Windows の終了 |

## 操作

- マウス: クリック / デスクトップ アイコンはダブルクリック / ウィンドウはタイトル バーでドラッグ
- `Enter` 既定のボタン、`Esc` キャンセル、`Tab` フォーカス移動、`Alt` + 下線付きの文字（例: `Alt+N` = 次へ）
- 画面の下のバー: 効果音、走査線、再生速度（×1 / ×2 / ×4）、表示倍率、最初からやり直す
- 開発者コンソールから `window.__setup.go('options')` のように、任意のページへ直接移動できます

入力した名前・プロダクト キー・コンピュータ名は最後まで引き継がれ、
[コントロール パネル] → [システム] で確認できます。

## 再現の方法

- **レイアウト**: 640×480 の実機スクリーンショットをピクセル単位で実測し、左パネル（幅 134px）、
  ウィザード（(141,60) に 492×390）、ボタン（75×23）などを同じ座標に配置しています。
- **色**: 第1・第2フェーズは VGA 16 色（面 `#c0c7c8` / 影 `#87888f` / タイトル `#0000a8`、
  青地は `#0000ff` と黒の市松ディザ）。デスクトップは `#3a6ea5` と `#d4d0c8`、
  タイトル バーは `#0a246a → #a6caf0` のグラデーションです。
- **画像**: ロゴ・アイコン・背景は `assets/` の PNG を使い、ドット絵のまま拡大表示します
  （表示倍率は 0.25 刻みに丸めています）。
- **フォント**: `MS UI Gothic` を優先し、無い環境では Google Fonts の `DotGothic16` で表示します。
- **文言**: 画面内の文章は日本語版の言い回しに合わせて書き起こしたものです。
  使用許諾契約書の本文は、実際の契約書ではなくこの作品用の文章です。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 読み込み用のラッパ |
| `style.css` | 画面とコントロールのスタイル |
| `js/core.js` | DOM ヘルパ、効果音、素材の参照、コントロール、ダイアログ |
| `js/setup.js` | MS-DOS 画面からログオンまでのセットアップ本編 |
| `js/desktop.js` | デスクトップ、スタート メニュー、付属アプリ |
| `js/main.js` | 画面の組み立て、拡大縮小、キーボード操作 |
| `assets/*.png` | 画面で使う画像（81 点） |
| `build.py` | すべてを 1 つの HTML にまとめるスクリプト |
